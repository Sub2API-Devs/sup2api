### 8. CCGateway 控制面板连接改造
- 现状：插件配置时直接 SSH 访问
- 改造：
  - **初始状态**：需要先安装控制面板，然后连接并上传所需镜像
  - **后续状态**：只需连接控制面板（不再需要 SSH）
  - **控制面板连接**：使用 HTTP 加密连接，需要 IP、端口、密钥
  - SSH 仅用于初始安装控制面板和第一次上传镜像
  - Docker 必须已安装（不自动安装）
  - 后续镜像更新通过控制面板连接上传
  - 控制面板提供镜像更新后自动启动功能
- 优先级：中
- 负责：agent-controller-setup
