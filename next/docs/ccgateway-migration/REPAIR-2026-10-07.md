## 核心直连与动态地址

模型数据链路：核心 → 校验主机指纹的 SSH direct-tcpip → 账号私网 HTTP 8787。控制器只处理管理和 `GET /accounts/<key>/connection` 发现，不再中转模型请求体/响应体。发现接口检查控制器 Bearer、ready 状态和当前 revision，返回的账号调用凭据只在核心内存使用。

核心限制目标为配置的 RFC1918 IPv4 地址池、固定端口 8787、相同 revision，并拒绝重定向/切换传输目标。连接发现有 15 秒上限。测试覆盖地址变化、地址池外私网、公网、回环、元数据地址、IPv4-mapped IPv6、过期 revision。

曾临时为 #21/#22 添加 SSH 目标地址用于定位。现已替换为专用 Key 的 `restrict,port-forwarding,permitopen="*:8787"`，不再维护逐账号 IP 列表。OpenSSH 此选项不支持 CIDR，SSH 层限制端口；私网池由核心校验。该专用 Key 应仅供可信核心使用，持有者独立使用 Key 时不受核心的地址池校验约束。未改其他 SSH Key。原配置有本机私有备份。新建账号或 IP 变化无需逐个编辑 SSH 配置。
