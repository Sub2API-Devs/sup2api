## 3. 发现并修复：官方版权声明没有保留

README 开头写"每个生成文件都保留了原始版权声明"。实际检查：

```
grep -rl 'All rights reserved' reconstructed --include='*.js' | wc -l   → 0
```

官方 2,859 个 JS 模块里 2,856 个开头有这行（另 3 个是 zstd 资源块）：

```
// (c) Anthropic PBC. All rights reserved. Use is subject to the Legal Agreements outlined here: https://code.claude.com/docs/en/legal-and-compliance.
```

阅读树生成器的文件头只写了"Reconstructed from the official … build"，没有带上这一行。git 历史里也从来没有过（2.1.316 的提交就没有）。所以这是从第一版起就存在的表述与实现的偏差，不是这一轮引入的。

**修复**（`tools/emit/readable.mjs`）：

- 新增 `COPYRIGHT_NOTICE`：从 `original/cli.js` 里按 `^// (\(c\) Anthropic PBC.*)$` 取，取不到才用写死的同一句兜底。这样换版本时不用改代码。
- 非 lazy / 非 worker 的文件头在结束 `*/` 之前插入 ` * <COPYRIGHT_NOTICE>`。

**修复后**：

| 项 | 结果 |
|---|---|
| 带声明的文件 | 7,460 个（含 vendor 与 runtime） |
| `reconstructed/src` 顶层声明行号 | 整体 +1（多一行文件头），`symbols.jsonl` 全量随之更新 |
| 构建 | 0 错误，2,857 个文件，35 秒 |
| 声明级等价 | 84,498/84,503，与修复前完全相同（文件头不参与比较） |
| 静态完整性 | 84,503/84,503，0 解析错误，自由标识符不变 |
| 运行对拍 | 98/98 |
